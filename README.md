## Featured Project — CareSpeak AI

**CareSpeak AI** is a privacy-first assistive communication platform designed to help people with speech and mobility limitations communicate more easily.

Key highlights:

- Hand and eye gesture-based communication
- Text-to-speech assistance
- On-device AI processing
- Nurse/caregiver dashboard with QR-based access
- Browser-based computer vision using MediaPipe and WebAssembly
- Designed with privacy in mind — user interaction data stays on the device

🔗 **Live Project:** https://care-speak.vercel.app/

## Getting Started

Clone the repository:

```bash
git clone https://github.com/humayunfaaz/AliFaazVerse.git
cd AliFaazVerse
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.

## Available Scripts

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run start    # Start the production server
npm run lint     # Run ESLint
```
